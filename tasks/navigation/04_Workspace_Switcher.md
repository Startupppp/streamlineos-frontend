# StreamlineOS Product Bible

# 04_Workspace_Switcher

## Purpose
Allow users to switch organizations/workspaces securely.

## Features
- Current Workspace
- Recent Workspaces
- Favorites
- Search
- Create Workspace (if permitted)

## Behaviour
- Preserve current product when possible.
- Refresh permissions after switching.
- Clear cached tenant data.
- Update notifications and search context.

## Security
- RBAC validated
- Tenant isolation
- Audit every switch

## Mobile
Presented as full-screen sheet.

## Acceptance
- Fast switching
- Secure
- Multi-tenant safe
