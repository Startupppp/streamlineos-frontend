# 06_Desktop_Sidebar

## Purpose
Enterprise desktop sidebar.

### Layout
- Product-specific navigation only
- Collapsible (280px/72px)
- Favorites
- Recent
- Section headers
- Nested menus (max 2 levels)

### UX
- Remember expanded state
- Tooltips when collapsed
- Active route highlighting
- Badges
- Keyboard navigation

### Rules
- No duplicate pages
- RBAC + Subscription aware
- Lazy load large menus

### Acceptance
Responsive, accessible, production ready.
