# 11_Administration

## Purpose
Central administration console for organization-wide configuration.

### Sections
- Organization
- People
- Access Control
- Subscription
- Platform
- Security
- Developer
- Audit

### Rules
- Visible only with admin permissions.
- Context-aware by organization.
- Changes are audited.
- Feature flags and subscription hide unavailable sections.

### Remove
- Duplicate Audit pages
- Duplicate Billing pages
- Duplicate Branch pages

### Acceptance
Single source of truth for administration.
