# StreamlineOS Product Bible

# 05_Global_Header

## Purpose
Define the persistent global header used across all products.

## Components
Left:
- Logo
- Workspace Switcher
- Product Switcher

Center:
- Global Search

Right:
- AI Assistant
- Calendar
- Chat
- Notifications
- Quick Create
- User Avatar

## User Menu
- My Profile
- My Tasks
- My Notifications
- Connected Apps
- Security
- Sessions
- Appearance
- Language
- Logout

## Responsive
Desktop:
Full header

Tablet:
Compact search

Mobile:
Logo + Search + Notifications + Avatar
Hamburger opens navigation.

## Acceptance
- Sticky header
- Accessible
- Keyboard shortcuts
- Responsive
