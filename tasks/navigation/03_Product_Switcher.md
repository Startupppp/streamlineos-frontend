# StreamlineOS Product Bible

# 03_Product_Switcher

## Purpose
Define the global Product Switcher that allows users to move between StreamlineOS products without leaving the workspace.

## Products
- Home
- CRM
- HRMS
- Projects
- Inventory
- Finance
- Helpdesk
- Documents
- Analytics
- AI
- Administration

## UX
- Fixed in top-left beside Workspace Switcher
- Grid view + searchable list
- Favorites
- Recently Used
- Pinned Products
- Keyboard shortcut (Ctrl/Cmd+K then type product)

## Rules
- Show only subscribed products.
- Hide products without RBAC access.
- Remember last opened product.
- Show badges for notifications.

## Mobile
Accessible from header drawer.

## Acceptance
- <2 clicks to any product
- RBAC aware
- Subscription aware
- Responsive
