# Security, Privacy, Audit And Permissions

## Permission Model
Support:
- Module permissions
- Action permissions
- Field-level permissions
- Record scope
- Sensitive case permissions

## Sensitive Data
- Salary
- Bank
- Tax
- Medical
- Grievance
- Disciplinary
- Background checks

## Audit
Audit every:
- profile change
- salary change
- bank/tax change
- document review
- policy change
- workflow approval
- automation run
- disciplinary/case action

## Acceptance Criteria
- Cross-org tests pass.
- Sensitive field access is tested.
- Audit logs are immutable to normal admins.
