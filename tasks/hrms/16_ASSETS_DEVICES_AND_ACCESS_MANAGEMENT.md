# Assets, Devices And Access Management

## Features
- Asset inventory
- Asset assignment
- Asset return
- Damaged/lost status
- Device assignment
- Software/app access requests
- Access removal on exit
- Uniform/PPE issue

## Automation
- On onboarding -> assign asset tasks.
- On exit -> recover assets and revoke access.
- On asset overdue -> notify HR/IT.

## Acceptance Criteria
- Asset lifecycle links to employee timeline.
- Offboarding cannot complete if required recovery pending unless overridden.
