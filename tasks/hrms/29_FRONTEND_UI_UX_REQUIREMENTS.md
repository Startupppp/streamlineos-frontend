# Frontend UI UX Requirements

## Design Direction
HRMS should feel like a serious operations product: clean, fast, information-dense, and easy for employees.

## Core Apps
- HR dashboard
- Employee directory
- Employee 360
- Attendance
- Leaves
- Policies
- Workflows
- Automations
- Documents
- Onboarding
- Offboarding
- Assets
- Performance
- Learning
- Engagement
- Cases
- Reports
- Settings

## UX Requirements
- Employee self-service first.
- Manager approval inbox.
- HR command center.
- Admin configuration screens.
- Clear locked/sensitive fields.
- Timeline on employee profile.
- No overlapping text on mobile.

## Acceptance Criteria
- Common employee action takes under 3 clicks.
- Admin can configure policy/workflow/template without developer.
- Mobile supports self-service and approvals.
