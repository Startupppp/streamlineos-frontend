# Employee Communications, Community And Events

## Goal
Make HRMS useful for culture and communication, not only admin.

## Features
- Announcements
- Policy broadcasts
- Event calendar
- Birthdays
- Work anniversaries
- Polls
- Kudos
- Communities/groups
- HR campaigns
- Read acknowledgements

## Acceptance Criteria
- HR can send targeted announcements.
- Policy announcements can require acknowledgement.
- Employee events appear on calendar.
