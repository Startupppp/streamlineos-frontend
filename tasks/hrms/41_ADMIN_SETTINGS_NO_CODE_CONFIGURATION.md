# Admin Settings And No-Code Configuration

## Goal
Admin must configure HRMS without engineering.

## Settings Areas
- Company HR profile
- Fiscal/work year
- Work week
- Locations
- Departments
- Roles
- Levels
- Employment types
- Policies
- Workflows
- Automations
- Templates
- Forms
- Permissions
- Notifications
- Integrations
- Data import/export

## Configuration UX
- Simple mode
- Advanced mode
- Preview effective rules
- Test workflow
- Test automation
- Version history
- Rollback

## Acceptance Criteria
- Admin can configure full HRMS setup from UI.
- Policy/workflow/template changes are versioned.
- Preview explains why a rule applies.
