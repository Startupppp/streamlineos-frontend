# Workforce Scheduling, Field Force And Mobile

## Goal
Support office, remote, shift, and field teams.

## Features
- Shift planning
- Roster planning
- Shift swaps
- Field check-in
- Route/visit logs
- Mobile attendance
- Offline punch capture later
- Geofence validation
- Location proof
- On-duty requests
- Work-from-home requests

## Mobile Requirements
- Employee self-service.
- Check-in/check-out.
- Leave request.
- Attendance regularization.
- Approval inbox.
- Payslip view.
- Document upload.
- Asset acknowledgement.

## Acceptance Criteria
- Field workers can check in with location.
- Shift swaps use approval workflow.
- Mobile UX supports core employee actions.
