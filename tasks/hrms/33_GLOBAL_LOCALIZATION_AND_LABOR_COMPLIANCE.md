# Global Localization And Labor Compliance

## Goal
Support country/location-specific HR rules.

## Features
- Country-specific holidays
- Local leave rules
- Local document requirements
- Local payroll handoff fields
- Work permit/visa tracking
- Labor law compliance reminders
- Statutory calendar
- Region-specific employee fields

## India-Specific Examples
- PAN
- Aadhaar optional where legally allowed
- PF/ESI/PT fields
- GST vendor/contractor support where needed
- TDS declarations
- Gratuity eligibility
- Shops and Establishment compliance reminders

## Global Examples
- Work authorization
- Visa expiry
- Right-to-work checks
- Country-specific tax IDs
- Local working time rules
- Region-specific privacy handling

## Acceptance Criteria
- Policies can be scoped by country/state/location.
- Compliance reminders are configurable.
- Local sensitive fields are permission-gated.
