# Employee Relations, Grievance And Cases

## Features
- HR case management
- Grievance
- Anonymous ethics hotline
- Disciplinary action
- Warning letters
- Investigation workflow
- Confidential notes
- Restricted documents
- Outcome tracking

## Security
These records require strict permissions and audit.

## Acceptance Criteria
- Cases are not visible in normal employee profile unless permitted.
- Anonymous submissions protect reporter identity.
- Every case action is audited.
