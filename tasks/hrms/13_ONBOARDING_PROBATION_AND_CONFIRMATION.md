# Onboarding, Probation And Confirmation

## Features
- Pre-joining checklist
- Joining checklist
- Role-based onboarding template
- Document collection
- Asset assignment
- Training assignment
- Buddy assignment
- Manager tasks
- HR tasks
- IT tasks
- Probation review
- Probation extension
- Confirmation letter

## Automation Examples
- On employee created -> start onboarding workflow.
- 7 days before joining -> send reminder.
- Joining date -> create IT access tasks.
- Probation end due -> create review workflow.

## Acceptance Criteria
- Onboarding tasks are template-driven.
- Probation duration is policy-driven.
- Confirmation is workflow-driven.
