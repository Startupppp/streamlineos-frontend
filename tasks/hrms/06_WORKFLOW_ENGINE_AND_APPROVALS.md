# Workflow Engine And Approvals

## Goal
All HR approvals and lifecycle processes must be configurable.

## Workflow Objects
- Leave request
- Attendance regularization
- Overtime request
- Comp-off request
- Expense reimbursement
- Travel request
- Employee data change
- Document review
- Asset request
- Onboarding
- Offboarding
- Probation confirmation
- Promotion
- Transfer
- Salary revision
- Resignation
- Termination
- Grievance case

## Workflow Features
- Multi-step approvals
- Parallel approvals
- Conditional approvals
- Delegation
- Escalation
- SLA/due dates
- Comments
- Attachments
- Reopen
- Cancel
- Audit

## Approval Assignment
Approvers can be:
- Direct manager
- Manager's manager
- HR role
- Finance role
- Department head
- Location HR
- Named user
- Dynamic expression

## Acceptance Criteria
- Approval chains are not hardcoded.
- Every workflow instance has state timeline.
- Rejections require configurable reason/comment rules.
