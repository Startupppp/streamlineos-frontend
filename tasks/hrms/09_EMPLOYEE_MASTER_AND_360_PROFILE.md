# Employee Master And 360 Profile

## Features
- Employee list
- Employee detail
- Employee edit
- 360 timeline
- Job info
- Personal info
- Contact info
- Emergency contacts
- Manager/reporting
- Documents
- Attendance
- Leaves
- Payroll summary
- Assets
- Goals
- Reviews
- Skills
- Training
- Cases
- Notes

## Change Governance
Employee changes can require workflow approval:
- Bank details
- Tax ID
- Address
- Emergency contact
- Salary
- Manager
- Department

## Acceptance Criteria
- Employee profile is a single source of truth.
- Sensitive tabs are permission-gated.
- Every profile change appears in timeline.
