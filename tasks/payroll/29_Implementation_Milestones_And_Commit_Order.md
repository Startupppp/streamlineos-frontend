# Implementation Milestones And Commit Order

## Milestone 1: Audit And Plan

- Read all payroll PRDs.
- Inspect existing payroll frontend/backend.
- Map current capabilities.
- Identify missing schema/API/UI.

## Milestone 2: Setup Wizard And Templates

- Template library.
- Five required templates.
- Toggle builder.
- Policy activation.

## Milestone 3: Payroll Command Center

- New product shell.
- Monthly readiness checklist.
- Exceptions panel.
- Payroll status lifecycle.

## Milestone 4: Calculation Engine

- Salary components.
- Formula support.
- Attendance/LOP.
- Bonuses/reimbursements/loans.
- Payroll preview.

## Milestone 5: Approval And Payout

- Approval workflow.
- Lock/reopen.
- Bank batch.
- Mark paid.
- Payslip publish.

## Milestone 6: Employee Self-Service

- Payslips.
- Declarations.
- Reimbursements.
- Loans.
- Bank details.

## Milestone 7: Reports And Compliance

- Payroll register.
- Tax reports.
- Journal export.
- Audit export.

## Commit Rule

Commit after every meaningful completed slice. Commit message should reference the PRD number.
