# Final Checklist Do Not Ship Unless

## Setup

- [ ] Owner can choose payroll template.
- [ ] At least five templates exist.
- [ ] Template details are previewable.
- [ ] Toggles are available before activation.
- [ ] Payroll policy version is created.

## Payroll Run

- [ ] Payroll run can be generated.
- [ ] Attendance/LOP inputs work.
- [ ] Reimbursements work.
- [ ] Bonuses/incentives work.
- [ ] Loans/advances work.
- [ ] Exceptions are shown.
- [ ] Preview is available.
- [ ] Approval workflow works.
- [ ] Locking works.
- [ ] Reopen requires reason.
- [ ] Mark paid works.
- [ ] Payslips publish.

## Employee

- [ ] Employee can view payslips.
- [ ] Employee can download PDF.
- [ ] Employee can submit declarations if enabled.
- [ ] Employee can submit reimbursements if enabled.
- [ ] Employee can request loan if enabled.

## Finance

- [ ] Bank payout report exists.
- [ ] Payroll register exists.
- [ ] Journal export exists.
- [ ] Cost center report exists.
- [ ] Variance report exists.

## Security

- [ ] RBAC tested.
- [ ] Bank details masked.
- [ ] Salary access protected.
- [ ] Audit logs exist.
- [ ] Payroll snapshots immutable after lock.

## CTO Signoff

Do not ship PayrollOS if it is only a payroll table and payslip generator. Ship only when it feels like a safe, guided, template-powered payroll product that an owner can trust.
