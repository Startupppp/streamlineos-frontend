# Current State Audit And Gap Map

## Existing Strengths

Current code appears to support:

- Payroll runs.
- Individual payslip generation.
- Payroll approval.
- Mark as paid.
- Salary structures.
- Salary structure templates.
- Tax module.
- Bank transfers.
- Reimbursements.
- Allowances.
- Bonuses.
- Incentives.
- Loans.
- FNF settlements.
- Payslip PDF/HTML.
- Employee payslip page.

## Product Gaps

- No owner-first payroll setup wizard.
- Templates exist technically but need product-grade template selection.
- No visible template marketplace/library experience.
- Limited toggle-driven payroll policy setup.
- Need payroll run checklist.
- Need exception queue before approval.
- Need payroll variance comparison.
- Need richer employee self-service.
- Need statutory configuration screens.
- Need accounting export.
- Need payment/bank payout workflow.
- Need contractor/global payroll modes.
- Need stronger audit, locking, and reopen controls.

## UX Gaps

- Current page is payroll table oriented.
- Needs a monthly payroll command center.
- Needs guided setup for first-time owner.
- Needs dense but calm review screens.
- Needs clear warning states before paying.

## Non-Negotiable Redesign

Payroll must feel like a financial operating product:

- Setup wizard.
- Template picker.
- Toggle panels.
- Payroll run command center.
- Employee payroll profile.
- Payslip designer.
- Compliance calendar.
- Finance approval console.
