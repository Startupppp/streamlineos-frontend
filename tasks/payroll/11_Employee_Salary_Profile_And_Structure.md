# Employee Salary Profile And Structure

## Purpose

Define each employee's compensation setup.

## Salary Profile Fields

- Employee.
- Employment type.
- Payroll template.
- Salary structure.
- Effective from.
- Effective to.
- Pay frequency.
- Currency.
- Bank account.
- Tax regime.
- Cost center.
- Department.
- Location.

## Salary Components

Each component has:

- Name.
- Type: earning/deduction/employer contribution.
- Calculation method.
- Fixed amount or percentage.
- Taxable flag.
- Payslip visibility.
- Include in CTC flag.
- Effective dates.

## UI

Employee salary page should show:

- Current monthly CTC.
- Gross/net estimate.
- Components table.
- Upcoming changes.
- Previous structures.
- Payslip history.

## Acceptance Criteria

- Salary changes are effective dated.
- Payroll uses the active structure for the month.
- Employee salary history is auditable.
