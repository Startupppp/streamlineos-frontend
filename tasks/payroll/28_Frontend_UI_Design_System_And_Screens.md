# Frontend UI Design System And Screens

## Purpose

Define the product UI.

## Visual Direction

PayrollOS should feel:

- Financially trustworthy.
- Calm.
- Precise.
- Dense but readable.
- Modern SaaS, not old HR table UI.

## Required Screens

- Payroll setup wizard.
- Template picker.
- Policy toggle builder.
- Payroll command center.
- Payroll run preview.
- Exception queue.
- Employee salary profile.
- Salary components.
- Payslip designer.
- Bank transfers.
- Tax declarations.
- Employee self-service.
- Reports.
- Settings.

## Component Rules

- Toggles for binary payroll features.
- Segmented controls for worker type/pay frequency.
- Inputs for amounts and percentages.
- Tables for payroll line items.
- Side drawers for employee detail.
- Warning banners for payout risks.
- Diff views for month-over-month variance.

## Acceptance Criteria

- Owner can understand setup visually.
- Payroll admin can work quickly in tables.
- Employee portal is simple and mobile-friendly.
