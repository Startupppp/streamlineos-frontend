# Product Principles And Non Negotiables

## Principle 1: Payroll Must Be Safe

Every payout-impacting change must be previewed, auditable, and reversible before lock.

## Principle 2: Setup Must Be Owner-Friendly

The owner should not need to understand every statutory rule on day one. Templates and toggles should guide them.

## Principle 3: Payroll Is A Monthly Workflow

A payroll run has stages:

- Prepare.
- Import inputs.
- Review exceptions.
- Preview.
- Approve.
- Lock.
- Pay.
- Publish payslips.
- Report.

## Principle 4: Employee Self-Service Reduces Admin Load

Employees should download payslips, submit declarations, track reimbursements, and understand deductions without HR intervention.

## Principle 5: Templates Are The Product Wedge

Templates make payroll sellable. Every template must be opinionated, editable, and safe.

## Non-Negotiable Acceptance

- Owner can pick a payroll template.
- Owner can turn features on/off using toggles.
- Admin can run payroll for a month.
- System shows exceptions before approval.
- Approver can compare this month vs previous month.
- Payroll can be locked after approval.
- Payslips can be published to employees.
- Reports can be exported.
