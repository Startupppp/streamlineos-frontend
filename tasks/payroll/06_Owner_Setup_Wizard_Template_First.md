# Owner Setup Wizard Template First

## Purpose

Let a business owner start payroll from a best-practice template instead of a blank form.

## Wizard Steps

### Step 1: Company Payroll Profile

Fields:

- Country.
- State/region.
- Legal entity name.
- Payroll currency.
- Pay frequency.
- Pay day.
- Payroll start month.
- Employee count.

### Step 2: Choose Payroll Template

Show at least five template cards:

- Indian Standard Payroll.
- Indian Startup Flexible Payroll.
- Contractor / Consultant Payroll.
- Sales Incentive Payroll.
- Global Remote Payroll.

Each card shows:

- Best for.
- Included components.
- Compliance toggles.
- Complexity.
- Recommended badge.

### Step 3: Toggle Features

Owner enables:

- PF.
- ESI.
- Professional tax.
- TDS/income tax.
- LOP from attendance.
- Overtime.
- Reimbursements.
- Bonuses.
- Incentives.
- Loans/advances.
- Contractor payments.
- Bank payout file.
- Payslip publishing.
- Approval workflow.

### Step 4: Review Generated Policy

Show:

- Salary components.
- Deduction components.
- Approval policy.
- Payroll calendar.
- Employee self-service options.

### Step 5: Activate

Activation creates:

- Payroll policy.
- Default salary components.
- Default deduction components.
- Payslip template.
- Payroll calendar.
- Setup checklist.

## Acceptance Criteria

- Owner can finish setup without manually creating every component.
- Template can be edited before activation.
- Activation is auditable.
