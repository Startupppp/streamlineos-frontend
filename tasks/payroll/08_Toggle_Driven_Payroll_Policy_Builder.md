# Toggle Driven Payroll Policy Builder

## Purpose

Let owners/admins configure payroll rules using clear toggles instead of raw configuration.

## Toggle Groups

### Earnings

- Basic salary.
- HRA.
- Special allowance.
- Travel allowance.
- Medical allowance.
- Meal allowance.
- Internet allowance.
- Overtime.
- Bonus.
- Incentive.

### Deductions

- PF.
- ESI.
- Professional tax.
- TDS/income tax.
- Loan EMI.
- Advance recovery.
- LOP.
- Other deductions.

### Inputs

- Attendance.
- Timesheets.
- Leave.
- Expenses.
- Sales incentives.
- Manual adjustments.

### Workflow

- Payroll maker-checker approval.
- Department approval.
- Finance approval.
- Lock after approval.
- Reopen with reason.

### Employee Self-Service

- Payslip download.
- Tax declaration.
- Reimbursement request.
- Bank details update.
- Loan request.

## UI Requirements

- Use switches/toggles for binary settings.
- Use sliders/inputs for percentages and caps.
- Use segmented controls for employee/contractor/global modes.
- Use preview panel showing formula impact.

## Acceptance Criteria

- Toggle changes show affected employees.
- Changes after activation create policy version.
- Risky changes require confirmation.
