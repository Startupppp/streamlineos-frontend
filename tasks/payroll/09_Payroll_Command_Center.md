# Payroll Command Center

## Purpose

Monthly home screen for payroll admins and owners.

## Header

Show:

- Current payroll month.
- Payroll status.
- Total gross.
- Total deductions.
- Net payable.
- Employees included.
- Exceptions count.

## Workflow Checklist

- Employee data verified.
- Attendance imported.
- Reimbursements approved.
- Bonuses/incentives approved.
- Loans applied.
- Tax declarations locked.
- Payroll preview generated.
- Exceptions resolved.
- Payroll approved.
- Bank file generated.
- Payslips published.

## Main Panels

- Payroll run status.
- Exceptions requiring action.
- Changes from previous month.
- Pending approvals.
- Payout readiness.
- Statutory readiness.

## Acceptance Criteria

- Admin can understand payroll readiness in under 30 seconds.
- Every warning links to the exact employee/issue.
- Payroll cannot be approved while blocking exceptions exist unless override is permissioned and logged.
