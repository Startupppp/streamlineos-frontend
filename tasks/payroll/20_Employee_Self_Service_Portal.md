# Employee Self Service Portal

## Purpose

Reduce payroll admin requests.

## Employee Features

- View payslips.
- Download payslip PDF.
- View salary structure if enabled.
- Submit reimbursement.
- Track claim status.
- Submit tax declaration.
- Upload tax proof.
- Request loan/advance.
- View loan balance.
- Update bank details if enabled.
- View FNF settlement if offboarding.

## Controls

Admin can toggle:

- Show salary structure.
- Allow bank update.
- Allow loan requests.
- Allow tax declaration.
- Allow reimbursements.
- Email payslip.

## Acceptance Criteria

- Employee sees only own payroll data.
- Sensitive bank/tax data is protected.
- Every employee action is logged.
