# Information Architecture And Navigation

## Preferred Route

- `/payroll`

Fallback:

- `/hr/payroll`, but UI should feel like a standalone product.

## Left Navigation

- Command Center
- Run Payroll
- Employees
- Salary Structures
- Templates
- Components
- Attendance Inputs
- Reimbursements
- Bonuses & Incentives
- Loans & Advances
- Taxes & Statutory
- Bank Transfers
- Payslips
- FNF Settlement
- Reports
- Settings

## Owner Setup Navigation

First-time payroll owner sees:

1. Choose template.
2. Configure toggles.
3. Add salary components.
4. Connect attendance/time inputs.
5. Configure statutory rules.
6. Configure bank payout.
7. Invite employees/self-service.
8. Run first payroll preview.

## Create Menu

- New payroll run.
- Add employee salary.
- Add salary template.
- Add earning component.
- Add deduction component.
- Add reimbursement.
- Add bonus.
- Add loan/advance.
