# Security, Permissions, Audit And Compliance

## Permissions
Support:
- record ownership
- team scope
- territory scope
- pipeline scope
- field-level access
- export permission
- delete/merge permission
- automation admin permission

## Audit
Audit:
- create/update/delete
- stage/status change
- assignment
- merge
- import/export
- automation run
- approval decision
- quote send/sign
- metadata/config changes

## Compliance
- consent for email/SMS/WhatsApp
- unsubscribe
- data retention
- deletion/anonymization
- source tracking

## Acceptance Criteria
- Cross-org tests pass.
- Sensitive/export actions are permission-gated.
- Audit log is searchable.
