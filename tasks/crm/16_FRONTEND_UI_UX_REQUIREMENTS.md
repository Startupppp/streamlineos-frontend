# Frontend UI UX Requirements

## Design Goal
Build a clean, powerful CRM workspace with minimal clutter and excellent configuration screens.

## Required Screens
- CRM home
- Sales inbox
- Leads
- Lead detail
- Deals pipeline
- Deal detail/deal room
- Contacts
- Companies
- Customer 360
- Quotes
- Activities/tasks
- Calendar
- Reports
- Automation studio
- Pipeline/stage settings
- Validation rules
- Assignment/scoring/SLA settings
- Import/export
- AI settings

## UI Rules
- No hardcoded badge labels/colors.
- Fetch stage/status/source metadata.
- Use dense tables for lists.
- Use Kanban for pipelines.
- Use drawer/detail pages for records.
- Use visual workflow builder for automations.

## Acceptance Criteria
- Admin can configure CRM metadata from UI.
- Sales rep can work daily from sales inbox.
- No text overlap on mobile/desktop.
