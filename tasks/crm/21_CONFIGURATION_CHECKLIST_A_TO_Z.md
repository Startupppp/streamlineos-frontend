# Configuration Checklist A To Z

## Admin Must Configure
- CRM modules enabled
- pipelines
- stages
- lead statuses
- lead priorities
- sources
- lost reasons
- activity types
- products
- price books
- quote templates
- custom fields
- custom objects
- validation rules
- stage requirements
- blueprints
- assignment rules
- scoring rules
- territory rules
- SLA policies
- automations
- sequences
- email templates
- WhatsApp templates
- notifications
- campaign attribution
- import mappings
- export permissions
- AI settings
- audit retention
- field-level permissions
- customer 360 visibility

## Final Rule
If a CRM value appears in a dropdown, badge, transition, automation, validation, report, filter, or chart, it must come from metadata/configuration unless it is a universal technical state.
