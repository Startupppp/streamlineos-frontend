# CRM Product Bible
# 17 Pipeline Management

## Purpose
Manage multiple sales pipelines with configurable stages.

### Features
- Multiple pipelines
- Drag & drop Kanban
- Stage rules
- Probability
- SLA timers
- Forecast values
- Pipeline analytics
- Pipeline permissions

### Views
- Kanban
- Table
- Funnel
- Forecast

### Acceptance
Supports unlimited pipelines per organization.
