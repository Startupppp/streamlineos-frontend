# Lead Management - Part 05 API Contracts

GET /api/crm/leads
GET /api/crm/leads/{id}
POST /api/crm/leads
PATCH /api/crm/leads/{id}
DELETE /api/crm/leads/{id}
POST /api/crm/leads/import
POST /api/crm/leads/export
POST /api/crm/leads/merge
POST /api/crm/leads/convert

Responses:
- Success
- Validation Error
- Permission Denied
- Duplicate Detected
- Conflict

All endpoints require Authentication, RBAC and Organization context.
