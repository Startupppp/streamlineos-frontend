# CRM Product Bible
# 41 Database Architecture

Purpose: Define scalable multi-tenant CRM database architecture.

Schemas: organizations, crm, audit.

Principles:
- UUID PKs
- Tenant isolation
- Soft deletes
- Audit tables
- Optimized indexes
- Read replicas supported

Core entities: Leads, Contacts, Companies, Deals, Activities, Tasks, Products, Quotes, Orders.
