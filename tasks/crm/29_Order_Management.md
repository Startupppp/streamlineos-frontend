# CRM Product Bible
# 29 Order Management

## Purpose
Convert accepted quotes into executable customer orders.

## Features
- Order creation from quotes/deals
- Products, quantities, pricing
- Approval status
- Fulfillment status
- Invoice handoff
- Partial fulfillment
- Cancellations
- Returns reference

## States
Draft → Approved → Processing → Fulfilled → Closed/Cancelled

## Integrations
Inventory, Finance, Notifications, Workflow.
