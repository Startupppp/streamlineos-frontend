# Deals, Forecast, Approvals And Revenue Process

## Deal Features
- Configurable pipelines
- Products/services
- Stakeholders
- Competitors
- Risks
- Next steps
- Mutual action plan
- Deal health
- Deal score
- Close plan

## Forecasting
- weighted pipeline
- commit
- best case
- pipeline
- omitted
- manager override
- forecast snapshots

## Approvals
Approval rules by:
- discount
- deal value
- margin
- stage
- product
- customer type
- payment terms

## Acceptance Criteria
- Approval role is not hardcoded.
- Won/lost is determined by stage metadata.
- Forecast uses configured probabilities.
