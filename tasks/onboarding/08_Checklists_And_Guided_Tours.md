# StreamlineOS Product Bible

# Customer Onboarding Platform

# 08_Checklists_And_Guided_Tours.md

## Purpose
Guide every customer to activation with contextual checklists.

## Checklist Sections
- Complete company profile
- Invite teammates
- Install recommended apps
- Connect email/calendar
- Import first data
- Create first record
- Use AI Assistant

## Guided Tours
- Interactive step-by-step
- Skip/resume
- Role-based
- Context aware
- Triggered on first visit

## Rewards
- Progress %
- Completion badges
- Celebrate milestones

## Analytics
Track completion, skips, drop-offs and time per step.

## Acceptance Criteria
Reduce onboarding abandonment and improve activation.
