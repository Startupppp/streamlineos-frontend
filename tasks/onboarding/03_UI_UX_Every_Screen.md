# StreamlineOS Product Bible

# Customer Onboarding Platform

# 03_UI_UX_Every_Screen.md

## Goal
Design every onboarding screen with a premium, guided experience.

## Screen Flow
1. Welcome
2. Business Goals
3. Industry
4. Company Details
5. AI Workspace Builder
6. Recommended Apps
7. Invite Team
8. Connect Integrations
9. Import Data
10. Success Dashboard

## UX Standards
- <3 clicks for common actions
- Progress indicator
- Resume later
- Keyboard accessible
- Mobile responsive
- Inline validation
- Helpful empty states
- Celebration animations at milestones

## AI Builder Screen
Show real-time progress:
- Creating organization
- Creating departments
- Installing apps
- Building dashboards
- Configuring AI

Never show a blank screen.

## Acceptance Criteria
Premium onboarding with zero confusion.
