# StreamlineOS Product Bible

# Customer Onboarding Platform

# 13_Empty_States.md

## Purpose
Never allow users to encounter a blank workspace.

## Principles
- Explain why the page is empty
- Suggest the next best action
- One primary CTA
- Optional AI assistance

## Empty States
- No customers → Import or Create
- No employees → Invite Team
- No inventory → Import Products
- No projects → Create Project
- No dashboards → Generate with AI

## AI CTA
'✨ Let AI build this for me'

## Acceptance Criteria
Every empty state educates, guides and converts into action.
