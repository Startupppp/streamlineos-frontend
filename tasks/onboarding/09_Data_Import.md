# 09_Data_Import.md

## Purpose
Allow customers to migrate existing business data.

## Sources
- CSV
- Excel
- Google Sheets (future)
- Zoho
- HubSpot
- Salesforce

## Import Types
- Customers
- Employees
- Products
- Inventory
- Projects

## Features
- Column mapping
- Validation
- Duplicate detection
- Preview
- Background processing
- Rollback support

## Acceptance Criteria
Reliable imports with detailed reports.
