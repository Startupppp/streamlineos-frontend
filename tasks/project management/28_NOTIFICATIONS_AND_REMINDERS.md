# Notifications And Reminders

## Channels

- In-app.
- Email.
- Chat.
- Mobile push future.

## Notification Events

- Assigned.
- Mentioned.
- Due soon.
- Overdue.
- Blocked.
- Approval requested.
- Client comment.
- Sprint started/completed.
- Release shipped.
- SLA breach.

## User Controls

- Quiet hours.
- Daily digest.
- Weekly digest.
- Mute project.
- Watch task.
- Only blockers.

## Edge Cases

- Notification storm.
- User muted project but direct mention occurs.
- Client receives internal notification.
- Timezone mismatch.
