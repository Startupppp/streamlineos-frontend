# Reports Analytics Project Health

## Project Health Score Inputs

- Overdue tasks.
- Blockers.
- Budget burn.
- Sprint velocity.
- QA failure rate.
- Team overload.
- Client pending approvals.
- Dependency delays.
- SLA breaches.

## Reports

- Project health.
- Portfolio health.
- Program health.
- Burndown.
- Velocity.
- Cycle time.
- Lead time.
- Cumulative flow.
- Workload.
- Overdue work.
- Budget vs actual.
- Bug trend.
- QA pass/fail.
- Team performance.
- Client status.

## Report Features

- Filters.
- Drilldown.
- Export CSV/PDF.
- Scheduled email.
- Client-safe report mode.

## Edge Cases

- Report includes deleted tasks.
- Client-safe report leaks internal notes.
- Metrics differ from board due to filters.
