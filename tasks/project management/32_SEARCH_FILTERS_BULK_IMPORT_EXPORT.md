# Search Filters Bulk Import Export

## Search

Search across:

- Projects.
- Tasks.
- Bugs.
- Docs.
- Comments.
- Files.
- Clients.
- Releases.

## Filters

- Project.
- Status.
- Type.
- Priority.
- Assignee.
- Due date.
- Sprint.
- Epic.
- Label.
- Custom field.
- Client visible.

## Bulk Operations

- Import tasks CSV.
- Export tasks CSV.
- Bulk assign.
- Bulk status change.
- Bulk label.
- Bulk archive.
- Bulk move sprint/project.

## Edge Cases

- CSV has invalid users/statuses.
- Bulk operation partially fails.
- Export includes restricted fields.
- Search result violates permission.
