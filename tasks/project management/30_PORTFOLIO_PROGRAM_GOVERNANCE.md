# Portfolio Program Governance

## Portfolio Features

- Group projects by strategic goal.
- Portfolio health.
- Cross-project dependencies.
- Budget across projects.
- Executive roadmap.

## Program Features

- Program milestones.
- Program risks.
- Program dependencies.
- Program reports.

## Governance

- Project approval before start.
- Required documents.
- Budget guardrails.
- Change-control policy.
- Closure checklist.
- Audit trail.

## Edge Cases

- Project belongs to multiple portfolios.
- Program milestone depends on archived project.
- Executive report includes restricted financials.
