# Testing And QA Plan

## Unit Tests

- Workflow transitions.
- Permission checks.
- Automation conditions.
- Sprint calculations.
- Dependency validation.
- Project health score.
- Custom field validation.

## Integration Tests

- Project creation from template.
- Task status transition with automation.
- Sprint start/complete.
- QA failed creates bug.
- Client approval flow.
- Time log to budget report.

## E2E Tests

1. Create project from Scrum template, run sprint, complete sprint.
2. Developer moves task to QA, tester fails, bug created, developer fixes, tester passes.
3. Client submits change request, PM estimates, client approves, tasks created.
4. Automation posts overdue alert to chat.
5. Project health report updates from blockers and budget burn.

## UI QA

- Desktop and mobile.
- Loading states.
- Empty states.
- Error states.
- Permission-hidden states.
- Large board performance.
