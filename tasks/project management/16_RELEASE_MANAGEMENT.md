# Release Management

## Release Fields

- Name.
- Version.
- Project.
- Owner.
- Target date.
- Status.
- Scope.
- Environment.
- Approval status.
- Release notes.

## Release Workflow

- Planned.
- In development.
- Code freeze.
- QA.
- UAT.
- Approved.
- Released.
- Rolled back.

## Release Gates

- No blocker bugs.
- Required tests passed.
- Product approval.
- QA approval.
- Deployment checklist.
- Rollback plan.

## Edge Cases

- Task added after code freeze.
- Release with unresolved critical bug.
- Rollback after completed release.
- Hotfix outside planned release.
