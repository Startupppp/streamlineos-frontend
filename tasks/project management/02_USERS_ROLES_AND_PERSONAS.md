# Users Roles And Personas

## System Roles

- Workspace owner.
- Admin.
- Portfolio owner.
- Program manager.
- Project owner.
- Project manager.
- Developer.
- Tester / QA.
- Designer.
- Reviewer.
- Finance user.
- Client user.
- Vendor / external collaborator.
- Viewer.

## Persona: Project Manager

Needs:

- Project plan.
- Task ownership.
- Timeline.
- Risks.
- Dependencies.
- Team workload.
- Client approvals.
- Reports.

## Persona: Developer

Needs:

- Clear assigned tasks.
- Acceptance criteria.
- Technical notes.
- PR/build/deployment status.
- QA handoff.
- Blocker escalation.

## Persona: Tester

Needs:

- Test cases.
- Test runs.
- Environment.
- Bug reporting.
- Regression status.
- UAT signoff.

## Persona: Client

Needs:

- Project progress.
- Milestones.
- Deliverables.
- Approvals.
- Change requests.
- Files.
- Status updates.

## Persona: Owner / Executive

Needs:

- Portfolio health.
- Delays.
- Budget burn.
- Risks.
- Delivery forecast.
- Team utilization.
