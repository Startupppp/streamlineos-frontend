# Incidents And SLA

## Incident Fields

- Title.
- Severity.
- Impact.
- Owner.
- Status.
- Timeline.
- Customer communication.
- Linked tasks.
- Root cause.

## Incident Workflow

- Detected.
- Investigating.
- Mitigating.
- Resolved.
- Postmortem.
- Follow-up.

## SLA Features

- Response timer.
- Resolution timer.
- Breach warning.
- Escalation.
- SLA report.

## Edge Cases

- SLA pauses during client waiting.
- Incident reopened.
- Severity changed after breach.
- Customer notification fails.
