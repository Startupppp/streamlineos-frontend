# Meetings Standups Action Items

## Meeting Object

Fields:

- Project.
- Title.
- Agenda.
- Attendees.
- Date/time.
- Notes.
- Decisions.
- Action items.

## Standups

Daily prompts:

- Yesterday.
- Today.
- Blockers.

## Action Item Conversion

Action item can become:

- Task.
- Subtask.
- Reminder.
- Risk.
- Decision.

## AI Meeting Support

- Summarize notes.
- Extract tasks.
- Detect blockers.
- Draft status update.

## Edge Cases

- Attendee not project member.
- Recurring meeting date conflict.
- AI creates duplicate action item.
