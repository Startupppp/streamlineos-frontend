# QA Test Management

## Objects

- Test plan.
- Test suite.
- Test case.
- Test run.
- Test result.
- Defect/bug.

## Test Case Fields

- Title.
- Preconditions.
- Steps.
- Expected result.
- Priority.
- Component.
- Linked requirement.
- Linked story/task.
- Automation status.

## Test Run Fields

- Sprint/release.
- Environment.
- Browser/device.
- Tester.
- Status.
- Started at.
- Completed at.

## Result Statuses

- Not run.
- Passed.
- Failed.
- Blocked.
- Skipped.

## Edge Cases

- Test case changed during active run.
- Tester leaves project.
- Failed test already has existing bug.
- Release approved while critical test failed.
