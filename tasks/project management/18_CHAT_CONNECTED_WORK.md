# Chat Connected Work

## Chat Requirements

Every project can have:

- Project channel.
- Sprint channel.
- Release channel.
- Incident channel.
- Client channel optional.

## Chat To Work

Users can:

- Convert message to task.
- Convert message to bug.
- Link message to task.
- Create reminder from message.
- Assign user from chat.
- Set due date from chat.

## Work To Chat

System posts:

- Task assigned.
- Task blocked.
- QA failed.
- Sprint started/completed.
- Release shipped.
- Client approval requested.
- SLA breach.

## AI In Chat

Ask:

- What is blocked?
- What changed today?
- Summarize sprint.
- Create tasks from this discussion.
- Draft client update.

## Edge Cases

- Chat message deleted after task created.
- Client channel mentions internal task.
- User without task permission clicks linked task.
- Automation posts too many messages.
