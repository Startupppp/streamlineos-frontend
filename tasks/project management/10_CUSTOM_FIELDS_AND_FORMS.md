# Custom Fields And Forms

## Custom Field Types

- Text.
- Long text.
- Number.
- Date.
- Date range.
- User.
- Dropdown.
- Multi-select.
- Checkbox.
- URL.
- Currency.
- Formula.
- Rating.

## Field Schema

- id.
- org_id.
- project_id nullable.
- name.
- type.
- options_json.
- required.
- applies_to_types.
- client_visible.
- default_value.
- validation_json.

## Forms

Form types:

- Task request.
- Bug report.
- Feature request.
- Change request.
- Client approval.
- Risk report.
- QA issue.

## Form Submission Actions

- Create task.
- Create bug.
- Add label.
- Assign owner.
- Post to chat.
- Request approval.
- Notify client/PM.

## Edge Cases

- Required custom field removed.
- Dropdown option deleted.
- Public form spam.
- Client submits invalid attachment.
