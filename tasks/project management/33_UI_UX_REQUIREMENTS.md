# UI UX Requirements

## Visual Direction

ProjectOS should be:

- Clean.
- Fast.
- Dense but readable.
- Operational.
- Configurable.
- Less cluttered than Jira.
- More structured than ClickUp.
- More powerful than Odoo/Zoho basics.

## Core UI Patterns

- Left navigation rail.
- Project switcher.
- Command menu.
- Saved views.
- Split panes.
- Right task drawer.
- Chat side panel.
- Drag/drop board.
- Dense table.
- Clear status chips.
- Quick create.
