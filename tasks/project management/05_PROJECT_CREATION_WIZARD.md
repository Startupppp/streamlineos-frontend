# Project Creation Wizard

## Goal

A user should create a complete configured project in minutes.

## Step 1: Basics

Fields:

- Name.
- Key/prefix.
- Description.
- Owner.
- Project manager.
- Department/team.
- Client optional.
- Start date.
- Target end date.
- Visibility.
- Project color/icon.

## Step 2: Project Type

Options:

- Scrum software.
- Kanban software.
- Client delivery.
- QA/testing.
- Bug tracking.
- Product roadmap.
- Marketing campaign.
- Implementation.
- Internal operations.
- Support/SLA.

## Step 3: Template

User selects a template or starts blank.

## Step 4: Feature Toggles

- Backlog.
- Sprints.
- Kanban.
- QA/test cases.
- Bugs.
- Releases.
- Time tracking.
- Budget.
- Client portal.
- Change requests.
- Forms.
- Chat.
- Docs/files.
- Automations.
- Approvals.
- DevOps links.
- AI assistant.

## Step 5: Workflow

Choose:

- Simple workflow.
- Developer workflow.
- QA workflow.
- Client delivery workflow.
- Support workflow.
- Custom workflow.

## Step 6: Team

Add members and roles.

## Step 7: Auto-Provision

System creates:

- Default views.
- Default statuses.
- Chat channel.
- Starter docs.
- Default milestones.
- Automation pack.
- Reports.

## Edge Cases

- Duplicate project key.
- Template deleted mid-creation.
- Client selected but client portal disabled.
- User lacks permission to invite members.
- Start date after end date.
