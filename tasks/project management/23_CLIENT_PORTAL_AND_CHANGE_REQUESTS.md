# Client Portal And Change Requests

## Client Portal

Features:

- Client dashboard.
- Milestones.
- Client-visible tasks.
- Deliverables.
- Files.
- Comments.
- Approvals.
- Change requests.
- Status reports.
- Invoice/time summary if enabled.

## Change Request Fields

- Title.
- Description.
- Requested by.
- Impact.
- Estimate.
- Budget impact.
- Timeline impact.
- Status.
- Approval owner.

## Change Request Workflow

- Submitted.
- Under review.
- Estimated.
- Awaiting approval.
- Approved.
- Rejected.
- In progress.
- Completed.

## Edge Cases

- Client submits request after project closed.
- Approved change request affects locked milestone.
- Client user removed while approval pending.
- Change request creates tasks in hidden internal workflow.
