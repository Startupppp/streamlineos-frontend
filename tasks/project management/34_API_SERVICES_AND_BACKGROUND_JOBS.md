# API Services And Background Jobs

## Service Areas

- Projects.
- Templates.
- Members/permissions.
- Work items.
- Workflows.
- Views.
- Sprints.
- QA.
- Bugs.
- Releases.
- Automations.
- Chat links.
- Comments.
- Files.
- Forms.
- Client portal.
- Time/budget.
- Reports.
- AI.

## API Requirements

- REST or typed RPC consistency.
- CRUD for all core objects.
- Pagination.
- Filtering.
- Sorting.
- Bulk actions.
- RBAC.
- Tenant scope.
- Audit events.

## Background Jobs

- Automation execution.
- Notifications.
- Recurring tasks.
- Report generation.
- AI summaries.
- SLA checks.
- Import/export.

## Edge Cases

- Job retries duplicate action.
- Report generated while data changes.
- Automation job fails midway.
- Webhook arrives for deleted entity.
