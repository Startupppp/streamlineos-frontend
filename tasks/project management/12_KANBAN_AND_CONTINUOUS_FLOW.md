# Kanban And Continuous Flow

## Kanban Features

- Board by workflow status.
- WIP limits.
- Pull policies.
- Cycle time.
- Lead time.
- Blocked aging.
- Cumulative flow.
- Throughput.

## WIP Limit Rules

- Soft warning.
- Hard block.
- Role override.

## Column Policies

Each status can have:

- Entry criteria.
- Exit criteria.
- Owner.
- SLA.
- Automation.

## Edge Cases

- WIP exceeded by bulk move.
- Blocked item stuck beyond SLA.
- Deleted status in board.
- Automation creates work exceeding WIP.
