# Resource Planning

## Resource Features

- Team capacity.
- Individual capacity.
- Workload heatmap.
- Skill matching.
- Leave/holiday awareness.
- Sprint capacity.
- Project allocation.
- Over-allocation alerts.

## Allocation Fields

- User.
- Project.
- Role.
- Start date.
- End date.
- Hours/week.
- Allocation percent.

## Views

- By person.
- By team.
- By project.
- By sprint.
- By skill.

## Edge Cases

- User allocated over 100 percent.
- Leave overlaps critical task.
- Skill required but no available resource.
- Allocation exists after project closes.
