# Project Templates

## Template Schema

Fields:

- id.
- org_id.
- name.
- category.
- description.
- icon.
- is_system_template.
- is_active.
- version.
- config_json.
- created_by.
- created_at.
- updated_at.

## Template Includes

- Workflow.
- Statuses.
- Views.
- Roles.
- Milestones.
- Task groups.
- Custom fields.
- Automations.
- Forms.
- Reports.
- Client visibility defaults.

## Required Templates

- Software Scrum.
- Software Kanban.
- QA Regression.
- Client Delivery.
- Product Launch.
- Implementation.
- Support/SLA.
- Marketing Campaign.
- Internal Operations.
- Bug Tracking.

## CRUD

- Create.
- Edit.
- Duplicate.
- Version.
- Archive.
- Restore.
- Apply.

## Edge Cases

- Template contains deleted user.
- Template contains disabled feature.
- Template version changed while applying.
- Template has invalid workflow transition.
