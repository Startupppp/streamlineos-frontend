# Bug And Issue Tracking

## Bug Fields

- Title.
- Description.
- Severity.
- Priority.
- Steps to reproduce.
- Expected result.
- Actual result.
- Environment.
- Browser/device.
- Screenshot/video.
- Affected version.
- Fixed version.
- Assignee.
- Reporter.
- QA owner.
- Reopen count.

## Bug Workflow

- New.
- Triaged.
- Assigned.
- In Progress.
- Fixed.
- Ready for QA.
- Verified.
- Reopened.
- Closed.

## Severity Values

- Blocker.
- Critical.
- Major.
- Minor.
- Trivial.

## Edge Cases

- Duplicate bug.
- Production bug linked to released version.
- Bug reopened after release.
- Attachment too large.
- Missing reproduction steps.
