# Developer Workflow And DevOps

## Developer Fields

- Branch URL.
- Pull request URL.
- Commit IDs.
- Build status.
- Deployment environment.
- Feature flag.
- Code review status.
- Technical notes.
- Ready for QA flag.

## Dev Workflow

- Ready for Dev.
- In Development.
- Code Review.
- Ready for QA.
- QA Failed.
- Ready for Release.
- Done.

## Integrations Future

- GitHub.
- GitLab.
- Bitbucket.
- CI/CD.
- Sentry.
- Deployment tools.

## Automations

- PR opened moves to Code Review.
- PR merged moves to Ready for QA.
- Build failed marks Blocked.
- Deployment posts to release chat.

## Edge Cases

- Linked PR belongs to another project.
- Build webhook arrives after task closed.
- Developer removed from project.
- QA fails after release.
