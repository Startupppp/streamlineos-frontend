## Versioning

Create version when:

- Article is published.
- Meaningful content changes.
- Verification occurs.
- Restore is performed.

Version view supports:

- Version list.
- Diff.
- Restore.
- Compare.
- Change summary.

## Concurrency

- Optimistic saves.
- Edit locks.
- Conflict detection.
- Compare/merge on conflict.

## RAG Impact

- Draft save updates private author-only chunks if enabled.
- Publish updates shared chunks.
- Version restore queues re-index.
