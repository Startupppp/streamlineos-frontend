# Search Hybrid Retrieval And Reranking

## Search Modes

- Keyword search.
- Semantic search.
- Hybrid search.
- Scoped search.
- Ask AI.

## Search Scopes

- All Knowledge.
- Current space.
- Current article.
- Selected articles.
- Private notes.
- Shared with me.
- Support KB.
- Public help center.
- Linked project/client/module.

## Filters

- Space.
- Collection.
- Owner.
- Author.
- Tag.
- Status.
- Visibility.
- Trust state.
- Updated date.
- Content type.

## Hybrid Retrieval

Use:

- Full-text/BM25 keyword retrieval.
- Vector retrieval.
- Metadata filters.
- Permission filters.
- Reciprocal rank fusion or equivalent.
- Reranker.

## Ranking Signals

- Exact title match.
- Heading match.
- Chunk semantic relevance.
- Keyword score.
- Verified/trusted state.
- Recency.
- User/team relevance.
- Article helpfulness.
- Citation usage success.

## Acceptance Criteria

- Search never returns inaccessible results.
- Verified content ranks higher where relevant.
- Reranking improves answer context quality.
