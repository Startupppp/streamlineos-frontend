# UI UX Requirements

## Design Direction

KnowledgeOS should feel:

- Clean.
- Fast.
- Calm.
- Trustworthy.
- Document-first.
- AI-ready.
- Operational for teams.

## Home Screen

Show:

- Ask AI search bar.
- Recently viewed.
- Favorites.
- Team spaces.
- Articles needing review.
- Knowledge gaps.
- Recently updated by my team.
- Suggested docs.

## Article Screen

Layout:

- Left: page tree / space navigation.
- Center: article content/editor.
- Right: table of contents, trust state, owner, review date, related articles, AI ask panel.

## Ask AI Panel

Must show:

- Question input.
- Scope selector.
- Answer.
- Citations.
- Confidence.
- Source freshness.
- Follow-up questions.
- “Create article from answer.”
- “Report wrong answer.”

## Upload Experience

Must show:

- Upload progress.
- Parse status.
- Index status.
- Extracted title/summary/tags.
- Duplicate warnings.
- Permission/indexing settings.

## Empty States

Required empty states:

- No spaces.
- No articles.
- No search results.
- No AI context.
- Upload failed.
- No permission.
- No review tasks.

## Mobile

Mobile must support:

- Read article.
- Search.
- Ask AI.
- Favorite.
- Comment.
- View citations.
- Basic edit for notes.
