# Personas And Primary Use Cases

## Persona: Founder / Owner

Needs:

- Company memory.
- Policies.
- SOPs.
- Team answers.
- Trusted AI answers.

## Persona: Team Manager

Needs:

- Team wiki.
- Process docs.
- Ownership.
- Review cycles.
- Onboarding guides.

## Persona: Employee

Needs:

- Fast answers.
- Private notes.
- Bookmarked articles.
- Ask AI.
- Clear source citations.

## Persona: Support Agent

Needs:

- Support KB.
- Customer-facing articles.
- Article suggestions.
- Ticket deflection.
- Gaps from support questions.

## Persona: Admin / Compliance

Needs:

- Permissions.
- Audit.
- Retention.
- Verification.
- Sensitive content controls.

## Primary Use Cases

- Create a private note.
- Create team SOP.
- Upload PDF policy and ask questions.
- Ask “What is our refund policy?” and get cited answer.
- Publish help center article.
- Detect stale docs.
- Convert repeated chat question into article.
- Find all docs related to a client/project/module.
- Export a space.
