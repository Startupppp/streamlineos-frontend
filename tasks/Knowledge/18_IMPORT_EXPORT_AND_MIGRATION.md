# Import Export And Migration

## Import Sources

- Markdown.
- HTML.
- CSV metadata.
- PDF.
- DOCX.
- Existing support KB.
- Existing internal docs.
- Future Confluence/Notion export.

## Import Flow

1. Upload import.
2. Preview structure.
3. Map spaces/collections.
4. Detect duplicates.
5. Validate permissions.
6. Create import job.
7. Import content.
8. Queue indexing.
9. Produce report.

## Export

- Article to Markdown.
- Article to HTML.
- Article to PDF future.
- Space to ZIP.
- Metadata to CSV.
- Audit export.

## Migration Rules

- Preserve slugs where possible.
- Preserve authors where possible.
- Preserve timestamps where possible.
- Preserve old URLs through redirects if public.
- Do not index migrated private content until permissions are verified.
