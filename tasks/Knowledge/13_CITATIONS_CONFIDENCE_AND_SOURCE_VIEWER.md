# Citations Confidence And Source Viewer

## Citation Requirements

Every answer citation must include:

- Article title.
- Space.
- Section heading.
- Page number if available.
- Version.
- Trust state.
- Last verified date.
- Snippet.
- Link.

## Source Viewer

When user clicks citation:

- Re-check permission.
- Open article at section.
- Highlight cited text.
- Show source metadata.
- Show stale/unverified warning.

## Confidence

Confidence should reflect:

- Retrieval relevance.
- Source quality.
- Source freshness.
- Agreement across sources.
- Coverage of question.

Confidence labels:

- High.
- Medium.
- Low.
- No reliable answer.

## Contradiction Handling

If sources conflict:

- Say sources conflict.
- Show both citations.
- Prefer verified/newer source if policy allows.
- Suggest review task.

## Acceptance Criteria

- No fabricated citations.
- Citations are clickable.
- Citation access is permission-checked.
- Answer is not shown as high confidence with weak evidence.
