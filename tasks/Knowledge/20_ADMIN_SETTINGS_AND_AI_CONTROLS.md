# Admin Settings And AI Controls

## Knowledge Settings

- Enable KnowledgeOS.
- Default company space.
- Default article visibility.
- Review intervals.
- Public help center enablement.
- Import/export permissions.

## AI Settings

- Enable AI Ask.
- Enable public help AI.
- Enable draft indexing.
- Allowed spaces for AI.
- Sensitive spaces blocked from AI.
- Embedding model.
- Reranker enabled.
- Top-K retrieval.
- Chunk size/overlap.
- Answer style default.
- Citation strictness.
- Credit/budget limits.

## Security Settings

- PII detection.
- Secret detection.
- Redaction before indexing.
- Audit retention.
- Data retention.
- Legal hold.

## Acceptance Criteria

- Admin can disable AI per space.
- Admin can see indexing status.
- Admin can re-index space/article.
- Admin can purge embeddings for deleted content.
