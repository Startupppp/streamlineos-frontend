# Frontend UI UX Requirements

## Design Direction
The UI should feel like a serious finance workspace: clean, dense, calm, and fast. Avoid marketing-style pages.

## Core Layout
- Left navigation for accounting sections.
- Header with date range, entity/company, and quick create.
- Main area optimized for tables, reports, and forms.
- Right drawer for details, audit, and activity.

## Required UX Patterns
- Quick create invoice/bill/journal.
- Powerful tables with search, filters, saved views.
- Drill-down from reports to transactions.
- Inline status badges.
- Approval banners.
- Export buttons.
- Empty states with next action.
- Keyboard-friendly data entry.

## Forms
Forms must support:
- Save draft
- Post/approve actions
- Validation summary
- Attachment upload
- Line item tables
- Tax calculations preview
- Accounting impact preview

## Reports
Reports must support:
- Date range
- Compare period
- Export
- Drill-down
- Print/PDF later

## Mobile
Mobile can be read/review/approve first. Heavy journal and reconciliation workflows can be desktop-first.

## Acceptance Criteria
- No text overlap.
- Tables remain usable on desktop.
- Mobile does not break.
- User can understand status and next action quickly.
