## Research and sales rule

The source pack contains explicit competitor observations and historical Build observations. Each implementation package must follow the linked screen/interface contract, then cite its original research ID, current actor/action evidence, and named competitor source before making a sales comparison. A Planned or Deferred row is never a current differentiator. The original `HAVE` rows stay Current unverified until the current application and competitor evidence satisfy the WOW criteria in the retained PM pack.

## Priority guardrail

The first activation sequence remains PM-011 invitation acceptance → PM-002 module assignment → PM-001 client grant activation. The crosswalk preserves later features without moving them ahead of this sequence.
