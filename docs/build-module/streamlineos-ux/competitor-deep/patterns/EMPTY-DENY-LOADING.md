# Pattern card — Empty vs Deny vs Loading

**ADOPT for Build.** Trust S1 for freelancers and Members.

| State | Visual | Copy | Primary action |
|-------|--------|------|----------------|
| Loading | Skeleton (≤1s target) | none / soft | none |
| Empty (allowed) | Illustration optional | “No X yet” | Create / Import |
| Deny | Lock / shield, no empty art | “You don’t have access to X” | Request access / Contact admin |
| Error | Alert | What failed + retry | Retry |

**Build fails today:** Member Projects empty while membership exists (UX-022) — reads as Empty, is Deny/scoping bug.
