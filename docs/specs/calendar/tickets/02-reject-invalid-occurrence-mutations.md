# 02: Reject invalid recurring occurrence mutations

**What to build:** Prevent occurrence edit and cancellation requests from creating exceptions for dates the recurring series never generates or no longer permits.

**Blocked by:** 01: Correct recurring occurrence windows and conflict checks.

**Status:** accepted

- [x] Editing or cancelling an instant not generated by the series rule is rejected without writing an exception.
- [x] Occurrences beyond the series end, already cancelled occurrences, and stale expected versions are rejected safely.
- [x] A rejected request does not bump the series version, cancel reminders, or queue provider synchronization.
- [x] A second edit of a moved occurrence resolves to the same nominal occurrence identity.
- [x] Negative tests cover wrong weekday, beyond-series, moved occurrence, cancelled occurrence, and concurrent version change.
