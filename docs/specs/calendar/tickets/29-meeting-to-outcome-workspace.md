# 29: Build the meeting-to-outcome workspace

**What to build:** Open a meeting into an authorized workspace containing agenda, permitted source context, files, notes, and reviewed follow-up actions.

**Blocked by:** 18: Complete invitations, guest lifecycle, RSVP, and reminders; 28: Propose source-owner actions with receipts.

**Status:** ready-for-agent

- [ ] Context from CRM, Build, documents, mail, chat, recordings, or transcripts appears only with current permission and consent.
- [ ] External guests receive only content explicitly shared with them.
- [ ] Generated decisions and follow-ups remain drafts until a user reviews each action.
- [ ] Applied actions show source linkage, owner, and committed/failed/declined receipts.
- [ ] Retention, recording consent, permission revocation, stale context, and partial-source failures are visible and tested.
