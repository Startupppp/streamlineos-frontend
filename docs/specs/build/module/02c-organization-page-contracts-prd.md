## Purpose

This is the executable page contract for every organization-level Build route
present in the 2026-09-19 source tree. BLD-02A owns keep/move/consolidate
decisions; this file defines what each retained or transitional page must
contain before that decision can close.

Every row inherits:

- loading, refreshing, empty, no-results, denied, offline/stale, error,
  conflict, and partial-success treatment from BLD-08;
- URL-shareable server search/filter/sort and truthful collection semantics
  from BLD-03;
- strict API, tenant/data-scope authorization, query, cache, and schema rules
  from BLD-05 and BLD-06;
- keyboard, screen-reader, touch, 200% zoom, responsive, and reduced-motion
  acceptance from BLD-08.

`None` means the page intentionally has no control of that kind. It must not be
replaced by a decorative control.
