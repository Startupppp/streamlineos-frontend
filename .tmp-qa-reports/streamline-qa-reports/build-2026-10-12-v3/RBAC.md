# RBAC matrix (UI-level; API authz not verified)
Owner: all. Org Admin+Build Admin: create/delete tickets, settings, invite; cannot change/remove owner.
Member+Build Member: only added projects; no create/edit/comment/cycle/settings controls.
Viewer (no Build): all /build pages Access Restricted. Outsider org: Page Not Found / 401.
Suspend clears sessions; remove revokes; Build toggle off -> "Module not enabled".
