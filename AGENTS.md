# Agent instructions

Read the relevant repository instructions before editing a module. Frontend work also follows `frontend/CLAUDE.md`. Preserve unrelated changes and verify the actual current source before acting on dated audit findings.

## Agent skills

### Issue tracker

HRMS and Payroll architecture tickets are local Markdown files under `docs/specs/hrms-payroll-reform/tickets/`; other skills use the local tracker convention in `docs/agents/issue-tracker.md`.

### Triage labels

Local tickets use the default five triage roles. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context root glossary and relevant existing ADRs. See `docs/agents/domain.md`.
