## Item 5d — Roster cursor pagination (DONE — backend + hook)

**Status:** Implemented. Backend + frontend hook complete. S09 must update app pages.

### What was done

**Backend — additive, backward-compatible:**

1. `backend/src/modules/module-access/dto/module-access.schemas.ts`  
   Added optional `cursor: z.coerce.number().int().nonneg().optional()` to `listMembersQuerySchema`.  
   Existing `page`/`pageSize` remain unchanged.

2. `backend/src/modules/module-access/module-access-groups.types.ts`  
   Added `MembersPage` interface: `{ data: FlatModuleMember[]; pagination: Pagination; nextCursor: number | null }`.

3. `backend/src/common/cache/cache-keys.ts`  
   Updated `moduleAccessMembers` key factory to accept optional `cursor?: number`.  
   When cursor is present the key uses `cursor:<value>` instead of `<page>:<pageSize>` — cursor and offset pages are never conflated in cache.

4. `backend/src/modules/module-access/module-access-roster.service.ts`  
   `listMembers` now passes `cursor` through to cache key and `fetchMembers`.  
   `fetchMembers` branches on cursor:  
   - **cursor present**: `WHERE membershipId > cursor ORDER BY organizationMembers.id ASC`, no COUNT query, `nextCursor = last row's membershipId if full page`.  
   - **cursor absent**: existing offset path unchanged (COUNT + name-sorted rows), `nextCursor` still emitted so consumers can switch modes.  
   Every early-return path emits `nextCursor: null`. Cap 100 unchanged.

**Frontend — additive, no breaking change:**

5. `frontend/hooks/api/module-access/types.ts`  
   Added `CursorPaginatedResult<T>` interface: `{ data: T[]; pagination: Pagination; nextCursor: number | null }`.

6. `frontend/hooks/api/module-access/members.ts`  
   Added `useModuleMembersInfinite(moduleKey, pageSize, options?)` using `useInfiniteQuery`.  
   `initialPageParam: undefined`, `getNextPageParam: (page) => page.nextCursor ?? undefined`.  
   Existing `useModuleMembers` (offset) is unchanged — no consumer breaks.

7. `frontend/hooks/api/module-access/index.ts`  
   Exported `CursorPaginatedResult` type and `useModuleMembersInfinite`.

8. `frontend/lib/query-keys/directory-and-ownership.ts`  
   Added `membersInfinite(moduleKey, { pageSize, userId? })` factory under `queryKeys.moduleAccess`.

### S09 handoff required

App pages in `frontend/app/(authenticated)/` that import `useModuleMembers` must be updated to use `useModuleMembersInfinite` when infinite scroll is desired. S09 owns those routes. The existing hook and offset pagination remain live; no page breaks until S09 makes the switch.
