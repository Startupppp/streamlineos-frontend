# Architecture work instructions

- Use [`prd/README.md`](prd/README.md) as the only source of pending work.
- Work only from a task explicitly listed in an indexed module lane.
- Treat the criterion registry, specifications, decisions, runbooks and evidence as reference material. Do not create tasks from their old `OPEN`, `FAIL`, `TODO` or `PENDING` wording.
- Verify current source and executable checks before changing a task status.
- Edit only the assigned lane. The release coordinator owns cross-lane dependencies, final integration, evidence reconciliation and commits.
- Do not create session reports, duplicate backlogs, scratch Markdown, or raw log files in the repository.
