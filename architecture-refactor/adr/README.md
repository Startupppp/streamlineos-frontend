# Architecture Decision Records

This directory holds decisions that alter tenancy, authorization, placement, event semantics, encryption, or cell topology, as required by the c28 PRD.

File naming: `NNNN-kebab-title.md` where NNNN is a zero-padded four-digit sequence.

Each ADR uses the following sections: **Status**, **Date**, **Context**, **Decision**, **Consequences**, **What would reverse this decision**.
